## Описание проекта
Интернет-маптеин мебели с системой управления процессами продаж и интерактивным 3D-конструктором комнат.

## Функционал
- Каталог товаров (столы, шкафы, тумбочки)
- Корзина и оформление заказа
- 2D/3D конструктор для "примерки" мебели
- Панель управления заказами для администратора
- Ограничение доставки только по Самаре

## Технологии
- **Backend:** Django + Django REST Framework
- **Frontend:** React + Vite
- **Database:** MySQL
- **3D графика:** Three.js + React Three Fiber
- **2D редактор:** React-Konva
- **Виртуализация:** VirtualBox + Ubuntu
